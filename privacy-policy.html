Privacy Policy

Shady URL Detector
Effective Date: August 24, 2026

1. About the Extension

Shady URL Detector is a browser extension designed to analyze website URLs for potentially suspicious patterns and provide users with a risk assessment.

2. Information Processed

The extension processes the URL of the webpage being analyzed. This may include:

  • Website domain
  • URL structure
  • URL protocol such as HTTP or HTTPS
  • Suspicious URL patterns
  • Domain characteristics

3. Local Processing

The current version of Shady URL Detector performs URL analysis locally within the user's browser.

The extension does not intentionally transmit analyzed URLs to an external server or third-party analytics service.

4. Data Storage

The extension does not intentionally maintain a permanent database of users' browsing history or analyzed URLs.

Temporary information may be used within the extension while performing an analysis or displaying a warning.

5. Data Sharing

Shady URL Detector does not sell, rent, or intentionally share users' analyzed URLs or personal information with third parties.

6. Browser Permissions

The extension uses browser permissions required for its functionality, including:

  • activeTab — used to work with the currently active webpage.
  • webNavigation — used to detect webpage navigation for automatic URL analysis.
  • notifications — used to display security warnings.

7. Third-Party Services

The current version does not intentionally use external URL-analysis APIs, advertising networks, or third-party analytics services.

8. Security Disclaimer

The risk score provided by Shady URL Detector is based on heuristic URL analysis.

A LOW RISK result does not guarantee that a website is completely safe, and a HIGH RISK result does not by itself prove that a website is malicious.

Users should exercise their own judgment before entering passwords, payment information, or other sensitive information on a website.

9. Changes to This Privacy Policy

This Privacy Policy may be updated if the extension's functionality or data practices change.

Updated versions will be made available through the project's published privacy-policy page.
